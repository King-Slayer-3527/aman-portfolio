# Aman Singh — Developer Portfolio

A sleek, modern, and interactive portfolio website showcasing software development, cybersecurity, and data analytics work.

🌐 **Live Website**: [https://King-Slayer-3527.github.io/aman-portfolio/](https://King-Slayer-3527.github.io/aman-portfolio/)

---

## 🚀 Features

- **Dynamic Interactive UI**:
  - Rotating Saturn-orbit skill badges around the avatar
  - Animated typewriter effect in the hero headline
  - Real-time scroll progress indicator and sticky glassmorphism navigation
  - Interactive mouse-following spotlight glow on project and profile cards
  - Scroll-triggered animated metric counters and skill progress bars
- **Modern Tech Stack**:
  - Built with clean, semantic **HTML5**, modern **CSS3** (CSS Grid, Flexbox, custom properties), and vanilla **JavaScript (ES6+)**
  - Zero external bloat or heavyweight framework overhead — blazing fast load times
- **Responsive & Accessible**:
  - Fully mobile-responsive layout for smartphones, tablets, and wide monitors
  - Support for `prefers-reduced-motion` for accessibility
- **Secure & Lightweight Media**:
  - Self-contained, privacy-protected portrait rendering with no raw image assets committed directly to the public code repository

## 🌐 Publishing to GitHub Pages

To view this portfolio live on the web at `https://King-Slayer-3527.github.io/aman-portfolio/`:

1. **Push this repository to GitHub**:
   ```bash
   git add .
   git commit -m "feat: initial commit for portfolio website"
   git branch -M main
   git remote add origin https://github.com/King-Slayer-3527/aman-portfolio.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository on GitHub: `https://github.com/King-Slayer-3527/aman-portfolio`
   - Click on **Settings** (top navigation tab)
   - In the left sidebar, click on **Pages**
   - Under **Build and deployment** -> **Branch**, select `main` and `/ (root)`, then click **Save**
   - In 1–2 minutes, your live portfolio will be published at:
     👉 **`https://King-Slayer-3527.github.io/aman-portfolio/`**
